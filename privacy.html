Privacy Policy

Last updated: August 9, 2026

Kumo is a browser extension designed to help users process visible Jira/Redcore task information and complete related CRM workflows more efficiently.

1. Data Kumo may process

When the user actively uses Kumo on supported pages, the extension may process task-related information visible on those pages, such as task identifiers, campaign identifiers, task type, vertical, start date, supported platforms, content fields, and other information required to provide the extension's features.

2. How the data is used

Kumo uses this information only to provide its disclosed functionality, including task parsing, structured task views, assisted form filling, templates, task history, and workflow tools.

3. Local storage

Where applicable, Kumo may store extension settings, templates, user preferences, and relevant task data locally in the user's browser so that these features remain available between sessions.

4. Website access

Kumo accesses supported Jira/Redcore pages only when necessary to provide its user-facing functionality. Kumo is not designed to monitor unrelated browsing activity.

5. Data sharing and sale

Kumo does not sell user data. Kumo does not share task data or browsing data with advertisers or unrelated third parties. Data is not used for advertising, creditworthiness, or unrelated profiling.

6. Remote code

Kumo does not intentionally load or execute remotely hosted JavaScript as part of the extension's functionality. Executable extension code is packaged with the extension.

7. Security

Kumo uses browser-provided security controls and aims to request only the permissions necessary for its disclosed functionality. Users should keep Chrome and the extension updated.

8. Data retention and deletion

Locally stored Kumo data can be removed by clearing the extension's stored data or uninstalling the extension. If a future version introduces server-side storage, this policy will be updated before such processing is used.

9. Chrome Web Store Limited Use

Kumo's use of information received from Chrome APIs is limited to providing and improving the extension's disclosed user-facing features and is intended to comply with the Chrome Web Store User Data Policy, including applicable Limited Use requirements.

10. Changes to this policy

This policy may be updated when Kumo's functionality or data practices change. The latest version will remain available at this URL with an updated date.
